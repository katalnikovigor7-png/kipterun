# Портфолио фотографа

Статический сайт: тёмная тема, оранжевые акценты, галерея с фильтрами по темам и просмотром фото на весь экран. Работает на GitHub Pages без сервера и сборки.

## Что где лежит

| Файл | Зачем нужен |
|---|---|
| `index.html` | Тексты: имя, «Обо мне», контакты |
| `style.css` | Внешний вид. Цвета меняются в самом верху, в блоке `:root` |
| `script.js` | Список фотографий (массив `PHOTOS` в начале файла) |
| `photos/` | Сами снимки. Сейчас там демо-картинки, их нужно заменить |

## Как сделать сайт своим

1. **Имя и тексты.** Откройте `index.html` и замените «Имя Фамилия», текст в блоке «Обо мне», почту и ссылки на соцсети. Места для замены помечены комментариями.
2. **Ваше фото в «Обо мне».** Положите снимок в `photos/` и поменяйте путь в `index.html` (`photos/about.svg` на, например, `photos/me.jpg`).
3. **Фотографии.**
   - Сожмите снимки: ширина 1600–2400 px, размер 300–800 КБ. Подойдёт экспорт из Lightroom или сайт squoosh.app.
   - Положите их в папку `photos/` и удалите демо-файлы `01.svg` … `09.svg`.
   - Откройте `script.js` и отредактируйте список `PHOTOS`: одна строка равна одному снимку. Подсказки в комментарии над списком.
4. **Цвет.** Оранжевый задаётся переменной `--amber` в `style.css`. Поменяйте её значение, и акценты поменяются везде.

## Как посмотреть сайт на своём компьютере

Дважды щёлкните по `index.html`, он откроется в браузере. Шрифты подгружаются из интернета, без него будут запасные, но всё продолжит работать.

## Как выложить на GitHub Pages

1. Зарегистрируйтесь на github.com и нажмите **New repository**.
2. Назовите репозиторий `ваш-логин.github.io` (тогда адрес сайта будет `https://ваш-логин.github.io`) или любым другим именем (тогда адрес будет `https://ваш-логин.github.io/имя`). Выберите **Public**.
3. В репозитории нажмите **Add file → Upload files**, перетащите **содержимое** папки (файлы `index.html`, `style.css`, `script.js` и папку `photos`, не саму внешнюю папку) и нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В разделе Source выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты сайт заработает. Адрес появится на этой же странице.

Чтобы обновить сайт позже, снова загрузите изменённые файлы через **Add file → Upload files**, они заменят старые.

## Свой домен

В **Settings → Pages → Custom domain** укажите купленный домен и следуйте подсказкам GitHub по настройке DNS.

## Важно знать

- Репозиторий публичный, поэтому любой может скачать файлы. Выкладывайте уменьшенные версии, а оригиналы храните отдельно. Для защиты можно добавить водяной знак.
- Рекомендуемый размер репозитория до 1 ГБ. Для сотен снимков лучше сжимать каждый до 500 КБ и меньше.
