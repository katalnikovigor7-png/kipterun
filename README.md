# Портфолио фотографа

Статический сайт: тёмная тема, оранжевые акценты, ровная сетка фотографий с фильтром по темам, просмотр на весь экран и раздел со ссылками на облачное хранилище. Работает на GitHub Pages без сервера и сборки.

## Что где лежит

| Файл | Зачем нужен |
|---|---|
| `index.html` | Тексты: имя, описание и ваше фото, «Обо мне», контакты и ссылки на облако |
| `photos.js` | Список фотографий (только имена файлов, без подписей) |
| `style.css` | Внешний вид. Цвета и сетка меняются в самом верху, в блоке `:root` |
| `script.js` | Работа галереи. Его менять не нужно |
| `update-photos.py` | Необязательный помощник: сам собирает `photos.js` из папок |
| `photos/` | Сами снимки. Сейчас там демо-картинки, их нужно заменить |

## Как сделать сайт своим

### 1. Имя, описание и ваше фото
Откройте `index.html` и замените «Имя Фамилия», описание в верхнем блоке, текст в разделе «Обо мне», почту и ссылки на соцсети. Места для замены помечены комментариями.

Ваше фото стоит в верхнем блоке справа, на месте заглушки «Ваше фото». Положите портрет в папку `photos/` (лучше вертикальный, пропорции 4:5, ширина от 800 px) и в `index.html` замените в блоке `intro-photo` путь `photos/me.svg` на свой, например `photos/me.jpg`. Если снимок другой формы, он обрежется по центру.

### 2. Фотографии (без подписей)
Сожмите снимки (ширина 1600–2400 px, размер 300–800 КБ, подойдёт экспорт из Lightroom или сайт squoosh.app) и положите в папку `photos/`. Дальше выберите один из двух способов.

**Способ А. Вручную.** Откройте `photos.js` и впишите путь к каждому файлу в нужную тему. Подписи, названия и размеры не нужны, только имена файлов. Если темы не нужны, оставьте простой список (пример в начале файла).

**Способ Б. Автоматически.** Если фото много, это быстрее:
1. Создайте внутри `photos/` подпапки по темам, например `photos/Портреты`, `photos/Свадьбы`. Название подпапки станет названием темы в фильтре.
2. Разложите снимки по подпапкам.
3. Запустите `python3 update-photos.py` (на Windows `python update-photos.py`). Скрипт сам перепишет `photos.js`. Нужен установленный Python.

Демо-файлы `01.svg` … `09.svg` и `me.svg` после замены можно удалить.

### 3. Ссылки на облако
В `index.html` найдите раздел «Все съёмки». Одна строка `<li>…</li>` равна одной ссылке. Поменяйте адрес (`href`), название съёмки и название сервиса. Чтобы добавить ссылку, скопируйте блок `<li>…</li>` целиком, чтобы убрать, удалите его. Подойдёт любое облако: Яндекс Диск, Google Drive, Dropbox, iCloud, Mega.

### 4. Цвет и сетка
- Оранжевый задаётся переменной `--amber` в `style.css`.
- Форма плиток: `--tile-ratio` (`1 / 1` квадрат, `4 / 5` вертикальная, `3 / 2` горизонтальная).
- Расстояние между фото: `--gap`.

В сетке все фото показываются в одинаковых плитках (обрезаются по центру), а по клику открываются целиком.

## Как посмотреть сайт на своём компьютере

Дважды щёлкните по `index.html`, он откроется в браузере. Шрифты подгружаются из интернета, без него будут запасные, но всё продолжит работать.

## Как выложить на GitHub Pages

1. Зарегистрируйтесь на github.com и нажмите **New repository**.
2. Назовите репозиторий `ваш-логин.github.io` (тогда адрес сайта будет `https://ваш-логин.github.io`) или любым другим именем (тогда адрес будет `https://ваш-логин.github.io/имя`). Выберите **Public**.
3. В репозитории нажмите **Add file → Upload files**, перетащите **содержимое** папки (файлы и папку `photos`, а не саму внешнюю папку) и нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В разделе Source выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты сайт заработает. Адрес появится на этой же странице.

Чтобы обновить сайт позже, снова загрузите изменённые файлы через **Add file → Upload files**, они заменят старые.

## Свой домен

В **Settings → Pages → Custom domain** укажите купленный домен и следуйте подсказкам GitHub по настройке DNS.

## Важно знать

- Репозиторий публичный, поэтому любой может скачать файлы. Выкладывайте уменьшенные версии, а оригиналы храните в облаке. Для защиты можно добавить водяной знак.
- Рекомендуемый размер репозитория до 1 ГБ. Для сотен снимков сжимайте каждый до 500 КБ и меньше. Основной архив съёмок лучше держать в облаке, а на сайт класть только лучшие кадры.
- Ссылки на облако открыты всем, у кого есть адрес. Если съёмка личная (например, для клиента), включите в облаке доступ только по ссылке или с паролем и не публикуйте её на сайте.
